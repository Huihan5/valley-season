### 2．第一幕 · 铸都 · 中介的话

“瓦莱维斯普公国，枫径庄园。”

中间人把那份文件推到桌面这边来时，窗外的王城笼罩在雨雾之中。银灰色的光把他办公室里所有的纸张都染成了同一种颜色。

“领主急缺一位临时管事，原先那位突然走了，连交接都没有。”他在整理另一叠文件，“秋收马上就到，庄园里的事情堆了快三个星期没人管。”

“为期三十天，食宿全包，报酬合理。瓦莱维斯普那边的活儿不复杂，但需要有人立刻过去。”

面前的男人合上文件夹。

“不过说实在的，冯·阿尔德男爵愿意担保一个外国人，这种机会不多见。”

### 3．第一幕 · 铸都 · 男爵的评估
> ID forgehold_2　｜　类型 场景

冯·阿尔德男爵在铸都的公国馆见了你。

他的办公室朝北，没有阳光，墙上挂着一幅枫径庄园的小幅画。

会面很短。他翻了你的简历。问了两个问题，第一个问题关于履历背景。你回答的时候他没有抬头。

第二个问题是：如果一本账上有一笔你看不懂的支出，你会先做什么。

“可以。”他在那份担保书上签了字，把它推回给中间人。整个过程没有超过十五分钟。

你起身的时候他已经在看别的文件了。离开公国馆前，你回头看了一眼那幅画。

铸都的天空还是那种银灰色。你手里攥着一张火车票。

### 4．第一幕 · 铸都 · 王国中央车站
> ID forgehold_3　｜　类型 场景

车站位于铸者之河的下游、铸都南岸市区的边缘。

大厅穹顶的青灰色石料取自北境山脉。光线从穹顶高处的窄窗倾泻而落，被空气中的微尘切成一道道光柱。钢铁和石材接得严丝合缝，这座城市的建筑从石头里长出来，又被人耐着性子一块一块铸出。

站台上的空气微凉，带着铁轨的金属气息和远处河水的湿意。几辆深灰色的列车安静地停靠在一旁。没有广告，没有多余的标识，只有车次编号和目的地名称用小号铜字嵌在窗框下。

你的车次是 08:40，终点站是河谷城北。

回头望去，铸者之河对岸的北岸上城区在晨雾中只露出轮廓。冠焰宫的塔尖、圣堂的穹顶、君王之跃石桥连成一条淡灰色的天际线，你没来得及去那边看过。也许以后也不会。

你上了车，找到座位，把行李放好。

车门关闭。

### 5．第二幕 · 河谷 · 离开山脉
> ID valley_4　｜　类型 场景

列车驶入第一条隧道时，车厢里暗了下来。

从铸都到河谷城，铁路要穿过北境山脉南麓的三条隧道和两个山口。这些通道直属王领管辖，沿途每隔一段就能看到路基旁的小型关卡和信号站。古老的石墙上长着苔藓，但信号灯是新的。

隧道里的温度被岩石吸走后只剩凉意，出了最长的那条隧道，光线突然涌进车厢。

### 6．第二幕 · 河谷 · 风景转换
> ID valley_5　｜　类型 场景

山脉的南坡和北坡是两个世界。

北坡是王城的那一边。灰色，岩石裸露，植被稀疏，天空永远是水洗过后的银。而南坡的颜色忽然变得多了起来：针叶林让位给了混交林，深绿色的冷杉之间出现金黄的桦树和正在变色的橡树。

山势在降低，河谷在展开。

列车沿着一条支流缓缓下行。窗外的树冠从灰绿变成黄绿，再变成金色。空气也不一样了，少了一丝金属般的冷冽，多了一种厚重的香甜。你后来知道那是落叶腐殖的味道。

偶尔经过一个小镇，你看见站台上的人在等待别的车次。他们穿得比铸都的人随意，颜色也更鲜活。

没有人注意到你。

### 7．第二幕 · 河谷 · 瓦莱维斯普
> ID valley_6　｜　类型 场景

过了第三个小站之后，地势彻底平缓下来。

窗外是大片的农田和牧场。沿河两岸铺展开的麦田中有些已经收割完毕，留下整齐的短茬和翻过的黑色泥土；有些还在等待，饱满的麦穗在风中低头，颜色是琥珀的金。远处的丘陵上有成片的林地，季节的变换把它们染成了一面面错落有致的斑斓旗帜。

牛群在田埂上缓缓走动。一座庄园自树丛后露出屋顶，石板屋顶上的烟囱冒着稀薄的炊烟。

那是谁家的庄园？你不知道。你要去的那一座还在更北的丘陵上。

列车开始减速。

### 8．第二幕 · 河谷 · 河谷城北
> ID valley_7　｜　类型 场景

河谷城主站在首府的城中心，它更大也更正式。而北站只有两条轨道，站台上铺着青灰色的石板，缝隙里野草生长。候车室的门半开着，里面空荡荡，墙上贴着公国林业法令的公告和本季集市时间表。

你拎着行李走出站台。九月底的午后，阳光还有些力气，但风里已经能闻到秋天。

站台旁边的空地上停着一辆朴素的两轮马车，深色的木车身上没有多余的装饰。一匹灰褐色的中型工作马正在安静地嚼草。马车旁边站着一个中年人。他穿着一件褪色的深色外套，帽檐压得很低。看见你，他点了一下头。在互相确认身份后，他把你的行李箱提上车尾的货架，然后走回驾座，等你上车。

整个过程没有一句寒暄。

### 9．第三幕 · 枫径 · 行径
> ID maplegate_8　｜　类型 场景

马车驶上了一条维护得还不错的土路，两侧是收割后的麦田和零星的果树。

车轮在硬土上发出有规律的轧声，蹄声是这段路上唯一的节奏。格雷格，你后来才知道他的名字。他坐在前面赶车，脊背挺直。

打量四周，你看见北面的丘陵线上有深色的林地。南面是开阔的谷地，谷水河在远处的弯口反射着午后的光芒。空气变得更甜。四下很静，你已经很久没有听到过这样的安静了。

途径一个三岔口，路标上用两种文字写着方向，上面一行是你看不懂的古语，下面一行是通用语。其中一条指向棘墙，另一条指向磨岭。

往北：枫径庄园，四公里。

格雷格让马拐了弯。

### 10．第三幕 · 枫径 · 大道
> ID maplegate_9　｜　类型 场景

在上坡路的尽头，道路两侧忽然出现了枫树。

枝干在头顶交汇，整整齐齐的两排形成了一条隧道。此刻是九月的最后时光，这条隧道正在燃烧。金色、铜色、将红未红的深橙色，叶片层层叠叠，光线像是碎掉的金箔，穿过缝隙落在石板路面上。偶尔一片叶子脱离枝头，在空中慢慢翻转，然后落在马的鬃上，你的眼前。

马车在枫径大道上走了不到五分钟，树冠之间显露建筑的轮廓。石墙、屋顶、正在冒烟的烟囱。

庄园到了。

格雷格停马下车，把你的行李放在庄园正门的台阶上。

“玛莎在里面。”

他牵着马往马厩走了。

### 11．第四幕 · 庄园 · 门厅
> ID manor_10　｜　类型 场景

门是开着的。你提起行李走进去。

厅内比外面暗，眼睛需要几秒钟才能适应。石地面，一道通向二楼的木质楼梯，右手边有一扇半开的门，里面传来烹饪的声音。一个女人在说话。语速很快，她在跟什么人交代事情。

然后声音停了。

“来了？”

她从门后走出来。四十多岁，围裙上沾着面粉，手在上面擦了两下才伸过来。“玛莎。厨房归我管。”

玛莎上下打量你，没有掩饰。

“路上还顺利吧。格雷格话不多，您别往心里去，他对谁都那样。”她说这话时已经转身往里走，“晚饭六点。您先上去看看房间。埃莱娜——”

楼梯上有脚步声。

### 12．第四幕 · 庄园 · 房间
> ID manor_11　｜　类型 场景

埃莱娜走在前面，两只手交叠在身前。她不说话，只在拐弯时侧身示意方向。

二楼走廊尽头的房间。她推开门，站在门口。

房间不大，一张单人床占据大部分位置。床单是新换的，折角压得整齐。一个衣柜，一张桌子，桌子对着窗，窗外是枫径大道。此刻天色已暗。

深色的桌面上面有一块长方形的痕迹。四条边很直，颜色比周围浅，像是原本放着什么东西，放了很久，久到把周围的木头晒得比它深。

“东西都收拾过了。”她退了半步，把门带上，“如果您需要别的，请跟我说。”

脚步在走廊上停了一下，然后才继续下楼。

### 13．第四幕 · 庄园 · 第一夜
> ID manor_12　｜　类型 场景

黑夜中的庄园静得出乎意料。

远处马厩里的一声响动，风吹叶落的声音，某个方向水在滴落。没有城市的底噪，每一个声音都能单独听清楚，之间是完整的安静。

你打开了行李箱。

明天开始，这座庄园归你管三十天。

## 二　主线事件

### 1．第 1 日 · 清晨｜第一个早晨
> ID day1_arrival

在你下楼的时候，庭院里已经有人了。

五六个人站在不同的位置上，各做各的事。有人在搬东西，有人在等着搬东西的人搬完。看见你，他们的动作没有停，但节奏变了。

玛莎从厨房门口探出来，手里还端着东西。她什么也没说。

你意识到他们在等你开口。

三个星期里，没有人告诉他们该做什么。麦子在地里，农具在库房，账本在楼上的桌子上。所有的东西都还在原地，等着有人说第一句话。

今天是十月一日。你有三十天。

### 2．第 3 日 · 正午｜账本的裂缝
> ID day3_ledger

在整理霍特曼留下的文件堆时，你发现最后两个月的账目对不上。

你把它们按日期抄在一张纸上，看了很久。数目不大，每笔三到五金卢，间隔不规律，摘要栏统一写着“杂项支出”。加起来不到二十金卢，在一座庄园一个月的流水里几乎看不出来。

但真正让你停下来的是另一件事：每一笔的日期、数目、经手人都记得清清楚楚，字迹和其他页面一样工整，上面没有任何涂改。

一个想遮掩的人不会记得这么清楚。

在最后一页的支出预算表上，你找了两遍，没有找到自己。

你的报酬不在这本账上。它出自男爵的私人预算，和马厩的修缮费、佃户的种子款、厨房的采买同样不在这本运营预算里。你管着这座庄园的每一枚金卢，而你自己是另一本账上的一行。

那本账你看不到。

埃莱娜替你寄出这封信。女仆看了一眼信封上的地址，但她什么也没说。

三天之后玛莎说今早有铸都那边的回信。

她认为你要找它。

### 3．第 4 日 · 正午｜添柴
> ID day4_hearth　｜　进入时写入 旗标 met_lorenz、旗标 unlockForgeChapel

炉堂那边有位匠师在等您。

你还没进过那间在主宅西翼的尽头的石室。不大的空间里嵌着一座石制炉膛，火烧得很低但稳定，空气里是旧烟和冷石的气味。

一个五十多岁的人正蹲在炉膛边往里放柴。他每放一根都等一会儿。

**洛伦茨匠师**　“洛伦茨。”他没有起身，“我给这一带的三座庄园做事。”

他把最后一根放进去，看着火焰重聚，然后才站起来拍手上的灰。

**洛伦茨匠师**　“这里换了一任管事，所以我来添一次柴。没有特殊的含义，就是让火知道换人了。”

**霍特曼**　“但我每次乘坐，都是为了回来。我不知道……不是为了回来的路，会是什么样的？”

他转过头。

**霍特曼**　“您走过那条路。”

你跟他说了你走过那条路。

你没有说南坡的颜色，也没有说树冠从灰绿变成金色。那些他早知道，他在这片林子里活了三十年。

你说的是别的。

你说你上车之前在站台上回过一次头。铸者之河对岸的北岸上城区在晨雾里只露出轮廓，冠焰宫的塔尖、圣堂的穹顶、君王之跃石桥连成一条淡灰色的天际线。

你说你当时想的是：我没来得及去那边看过。

然后你想的是：也许以后也不会。

你说你就是在想到第二句的时候，车门关上了。

他听完之后很久没有说话。

**霍特曼**　“我在铸都住了十一个月。”他说，“我一次也没有过河到北岸去。”

**霍特曼**　“十一个月。”

他看着自己的手。

**霍特曼**　“我一直想着回来以后有很多事要做。”

然后他问了第二个问题。

然后是第三个。

#### ◇ 变体｜ludwig

他是十一月三日到的。那一周，贵族院的人都该在铸都。

路德维希直接上了二楼那间屋。

门关着，关了很久。你在楼下的办公室，什么也没有听见，那间屋的门很厚，而且他们两个人说话的声音本来都不大。

他下来的时候你正好在门厅。

他站在楼梯下面，一只手还搭在扶手上。

**路德维希男爵**　“他问我铸都是什么样。”

过了一会儿他往门口走。走到门口他停下来，看着外面那几级台阶。

**路德维希男爵**　“霍特曼小时候不爱说话。”他说，“我比他大十岁。他跟着他父亲在这儿跑，那时我在铸都上学，一年回来两回。每次我回来，他都在门口那几级台阶上坐着。”

他推开门走出去，站在台阶上，背对着你。

**路德维希男爵**　“后来我送了他去学苑上学，管事们的孩子都想去那儿。但我没有问过他想做什么。”

外面的枫树全空了。

**路德维希男爵**　“现在还来得及。”

#### ◇ 变体｜henk

那天晚上你在办公室对账。西边储藏间里那些东西的来处，账上没有记。

你在纸上写了一行，又划掉了。

楼上那间屋的灯还亮着，埃莱娜在。

那个人躺在那张床上，是因为他拒绝了亨克。

而你留在这座庄园里，有一部分原因是你没有拒绝。

你把那一页翻过去了。

#### ◇ 变体｜festival_mirror

圣火节那天中午，庄园的长桌摆在庭院里。

霍特曼还上不了桌。埃莱娜端了一份食物上楼。

你坐在桌子中间。主位空着，男爵在楼上，他说他一会儿下来。

他后来没有下来。

吃到一半的时候，你面前多了一碟东西。那是一碟腌菜，你上个月在厨房随口说过喜欢。

玛莎在桌子另一头给人添酒。

天黑之后人散了。你上楼的时候路过那间屋，门开着一条缝。

桌上有两个盘子。

一个盘子是路德维希的，他吃了大半。

另一个盘子在床边的凳子上，里面的食物也被吃了大半。

### 6．尾声｜尾声 · 路德维希的三天
> ID epilogue

每年圣火节，路德维希男爵回来住三天。

这三天里他不进城，也不拜访任何邻庄。亨克每年都派人来递话，每年都被回掉。

#### ◇ 变体｜ending3

男爵下午才到。他吃得很少，但在庭院里待到了最后。

#### ◇ 变体｜ending4a

他查账，但只翻了几页就合上了。三天里他去了两次门厅那张窄桌，木匣放在那儿。

#### ◇ 变体｜ending4b

他上楼三次。第三次待了一个多小时。

#### ◇ 变体｜close

男爵第三天下午走。

车在庄园门口等着。在上车之前他会做一件每年都做的事：在枫径大道的入口站一会儿，看那两排树。

十一月底，树已经空了。

**格雷格**　“老爷每年都在那站一会儿。这是以前的老爷们留下的东西。”他少见地多话了。

“站多久？”

**格雷格**　“不长。”他说，“一分钟，两分钟。”

冯·阿尔德上了车。车子沿着那条隧道往南走，走到看不见。

然后庄园安静下来。

冬天就要来了。
