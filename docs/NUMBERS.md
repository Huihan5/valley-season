# 河谷季 · 数值设计表

Valley Season — Numerical Design Reference · GDD Supplement v1.0

---

## 一、时间预算总览

游戏总时长30天，每天3时段。玩家的一切决策本质上是**时间分配**。

| 类目 | 数量 | 备注 |
|------|------|------|
| 总时段 | 90 | 30天 × 3时段 |
| 自由白天时段 | 60 | 上午30 + 下午30 |
| 受限晚间时段 | 30 | 仅办公室/NPC交谈/休息 |
| 固定事件占用 | 约10-13时段 | 取决于玩家选择（如是否参加狩猎季） |
| 实际可支配白天时段 | **约47-50** | 这是真正的"货币" |

### 时段消耗参考

| 行动 | 消耗 |
|------|------|
| 庄园内任意行动 | 1时段 |
| 前往河谷城集市 | 2时段（上午+下午） |
| 前往邻庄/神殿 | 2时段（上午+下午） |
| 前往猎场 | 2时段（上午+下午） |
| 晚间行动 | 1时段（受限选项） |

### 关键约束

- 集市仅周三、周六开放 → 30天内最多8个集市日
- 猎场仅Day 18后开放 → 最多约6天可用
- 外出行动(2时段)的机会成本极高：一次集市 = 放弃一整天的收割/采伐

## 二、资源系统

### 2.1 粮食储备（Grain）

粮食是秋收的核心产出，从零开始积累。

| 参数 | 数值 | 说明 |
|------|------|------|
| 初始值 | 0 | 秋收尚未开始 |
| 可收割总量上限 | 140 | 所有耕地的理论总产出 |
| 冬季口粮需求 | 60 | 庄园全员（≈100人）过冬4个月 |
| 税赋 | 总收成 × 14.5%（向上取整） | 如收成100，则缴15 |
| 春播种子预留 | 15 | 明年播种所需 |
| **安全线** | **≈90** | 口粮60 + 税赋约13 + 种子15 |
| 理想目标 | 100+ | 余粮可在集市出售换金卢 |

**收割效率等级**（渐进式，需前期投入解锁）：

| 准备状态 | 基础产出/时段 | 解锁条件 |
|----------|--------------|----------|
| 未准备 | 3 | 默认 |
| 农具已修 | 5 | 花1时段 + 15金卢进行农具维修 |
| 农具+仓储 | 6 | 额外花1时段 + 10金卢清理仓储 |
| 全部准备 | 7 | 额外花1时段召开佃户会议（需佃户整体信任≥0） |

未清理仓储时，储存上限为80（超出部分损耗）。

**天气修正**：

| 天气 | 修正 |
|------|------|
| 晴天 | +1 |
| 多云 | ±0 |
| 阴雨 | -2 |
| 霜冻 | 收割效率不受影响，但未收割作物每天损失剩余量×10% |
| 大雾 | ±0（但外出时间+1时段） |

**数值测试**：
- 最优路线：花3时段+25金卢做全部准备 → 效率7-8/时段 → 约12-14时段达到安全线(90) → 非常舒适，可兼顾社交和调查
- 中等路线：只修农具 → 效率5-6/时段 → 约16-18时段达安全线 → 可行但需要取舍
- 无准备路线：效率3/时段 → 需要30个时段 → 几乎不可能完成其他任何事，且大概率不够

这个梯度确保"前期投入vs直接开始"的权衡是有意义的。

### 2.2 金卢（Guldmark）

庄园的流动资金。

| 参数 | 数值 | 说明 |
|------|------|------|
| 初始值 | 50 | 账目记录55，实际调查后确认50（差额5是Hartmann线索之一） |
| 日常运营消耗 | 2/天 | 食物、薪资、杂项，自动扣除 |
| 30天总运营消耗 | 60 | 如无收入则30天后 = -10，破产 |
| 月末安全线 | ≥15 | 冬季启动资金 |

**收入来源**：

| 来源 | 收入 | 条件 |
|------|------|------|
| 集市出售粮食 | 1.5金卢/单位 | 需前往集市（2时段） |
| 集市出售木材 | 3金卢/单位 | 需前往集市（2时段） |
| 果园采摘+出售 | 5-8金卢/次 | 1时段采摘 + 集市出售 |
| 采集（蘑菇/草药） | 2-3金卢/次 | 林地行动 |
| Millridge合作路线 | 木材售价+1金卢/单位 | 需与Henk达成协议 |

**主要支出**：

| 项目 | 花费 | 时机/备注 |
|------|------|----------|
| 农具维修 | 15金卢 + 1时段 | 提升收割效率，建议前期 |
| 仓储清理（雇临时工） | 10金卢 + 1时段 | 解锁储存上限，建议前期 |
| 佃户住宅维修（全修） | 40金卢 + 10木材 | Day 10请愿，5户×8金卢+2木材 |
| 佃户住宅维修（部分） | 16-24金卢 + 4-6木材 | 优先2-3户，需做优先级判断 |
| 马厩屋顶修缮 | 12金卢 + 3木材 | 可选，Gregor信任+1 |
| 狩猎季礼物/装束 | 10金卢 | 可选，社交场合得体加分 |
| 集市日常采购 | 3-5金卢/次 | 按需补给 |

**预算压力测试**：

```
支出侧（30天）：
  日常运营    60
  准备投入    25  （农具15 + 仓储10）
  佃户维修    24  （部分修，3户）
  ─────────────
  基本支出   109

月末安全线    15
  ─────────────
  总需       124

收入侧：
  初始金卢     50
  需要赚      74

收入路径（示例）：
  出售15单位木材    45  （5次采伐×3单位 + 初始8中取7出售）
  果园苹果出售      24  （4次集市×6金卢均值）
  零散采集          8   （4次×2金卢）
  ─────────────────
  预计收入          77  → 略有盈余

如果全修佃户住宅（40金卢+10木材）→ 需要多卖木材或粮食，更紧张
```

设计意图：金卢不会让人破产，但也不允许大手大脚。每一笔大额支出（佃户维修、马厩修缮、狩猎季花费）都是一次资源分配决策。

### 2.3 木材（Timber）

| 参数 | 数值 | 说明 |
|------|------|------|
| 初始库存 | 8 | 仓库现有 |
| 本季采伐额度 | 25 | 公国法令限定，不可超出 |
| 采伐产出 | 3单位/时段 | 晴天/多云均可 |
| 阴雨天 | 林地工作暂停 | 不能采伐 |
| 冬季取暖储备 | ≥5单位 | 月末至少保留 |
| 集市售价 | 3金卢/单位 | 与Millridge合作后4金卢/单位 |
| 维修用量 | 佃户住宅每户2单位，马厩3单位 | 无法用金卢替代 |

木材的核心矛盾："出售换钱"还是"留着修东西"。采伐额度25 + 初始8 = 总共33单位可用。如果全修佃户住宅(10) + 马厩(3) + 冬季储备(5) = 18单位，只剩15单位可出售(45金卢)。

### 2.4 声望（Renown）

| 参数 | 数值 |
|------|------|
| 初始值 | 0 |
| 范围 | -10 到 +10 |

**声望变动一览**：

| 事件/行动 | 变动 |
|-----------|------|
| 成功处理佃户请愿（Day 10，全修） | +2 |
| 成功处理佃户请愿（部分修，公正排序） | +1 |
| 拒绝/忽视佃户请愿 | -2 |
| Thornwall晚宴表现得体（Day 7） | +1 ~ +2 |
| Thornwall晚宴表现失礼 | -1 ~ -2 |
| 缺席Thornwall晚宴 | -1 |
| 参加狩猎季开幕（Day 18） | +1 |
| 狩猎季表现出色 | 额外 +1 |
| 缺席狩猎季 | -1 |
| 公正解决边界纠纷 | +1 ~ +2 |
| 税务审计顺利通过（Day 12） | +1 |
| 税务审计出问题 | -2 |
| 参加秋季感恩仪式 | +1 |
| 违反采伐法令 | -3 |
| 集市维持良好商誉 | +1（累计，首次交易后） |
| 帮助社区小事件（随机事件） | +1/次 |

**阈值效果**：

| 声望值 | 效果 |
|--------|------|
| ≥6 | 被本地社区视为"自己人"，解锁额外对话和合作选项 |
| ≥8 | 结局三"河谷的人"的必要条件之一 |
| 3 ~ 5 | 正常，受尊重但仍被视为外来者 |
| 0 ~ 2 | 中性，不好不坏 |
| ≤-3 | 佃户消极怠工：收割效率 -1/时段 |
| ≤-5 | 邻庄关系恶化，部分社交选项关闭 |
| ≤-7 | 结局四"被解雇"的高风险区 |

## 三、关系系统

所有NPC信任值初始为0，范围 -5 到 +5。

### 3.1 信任变动方式

核心原则：**信任通过行动和决策间接获得，不通过"选了对的对话选项"直接获得。** 这避免了"讨好模拟器"的陷阱。

| NPC | 主要信任增加途径 | 主要信任减少途径 |
|-----|-----------------|-----------------|
| Gregor | 修缮马厩(+1)、帮忙照顾马匹(+1)、展现对土地的尊重(+1) | 催促他说话(-1)、忽视马匹状况(-1) |
| Marta | 处理她提到的佃户诉求(+1)、把她当合作者(+1) | 忽视她传达的信息(-1)、命令式态度(-1) |
| Lena | 保持尊重但不过分关注(+1)、保护她不受牵连(+1) | 当众让她难堪(-1)、泄露她的信息(-1) |
| Baroness Elke | 晚宴得体且不过分(+1)、边界纠纷中尊重历史(+1) | 不做功课就谈边界(-1)、过分殷勤或对抗(-1) |
| Baron Henk | 认真回应商业提议(+1)、展现商业头脑(+1) | 完全无视提议(-1) |
| Father Lorenz | 参加感恩仪式(+1)、对话中展现真诚(+1) | 对宗教活动明显不屑(-1) |

### 3.2 信任值解锁的信息

这是游戏叙事最关键的机制——NPC的信息分层。

| NPC | 信任 ≥3 解锁 | 信任 ≥4 解锁 |
|-----|-------------|-------------|
| Gregor | Hartmann离开前的异常行为（深夜独自去林地、办公室灯经常亮到凌晨） | Hartmann的马鞍去向——他没带走马鞍，而是藏在了某个地方。这是关键物证线索。 |
| Marta | 庄园内部的完整人际关系图谱，谁和谁有过节，佃户里谁最可信 | Hartmann最后几周的情绪剧变细节——从疏远变为恐惧，以及他最后一次和Marta说的话 |
| Lena | Hartmann离职前最后一晚在办公室烧了东西 | 她偷偷保留的一页被烧剩的文件碎片（物证） |
| Baroness Elke | Hartmann曾来找她谈过"一件不寻常的事"（方向性线索） | 在关键时刻为你在贵族圈中担保（社交保护） |
| Baron Henk | 他的林地里也发现过类似的古老标记（扩展调查范围） | 在你需要时提供实际物资支持（紧急金卢/木材） |
| Father Lorenz | 暗示Hartmann来找他时的情绪状态和话题方向 | 直接告诉你Hartmann在害怕什么 |

### 3.3 反面效果

| NPC | 信任 ≤-2 | 信任 ≤-4 |
|-----|----------|----------|
| Gregor | 不再回答任何问题，只用单音节应答 | 不通知你马匹健康问题，可能导致运输事故 |
| Marta | 不再主动传达佃户诉求，你失去"情绪晴雨表" | 在厨房散布对你的负面评价，佃户整体信任-1 |
| Lena | 回避你，不再清理你的办公室（你可能错过文件线索） | 向Thornwall的仆人透露庄园内部信息 |
| Baroness Elke | 正式场合对你冷淡，社交损失 | 在贵族圈中公开质疑你的资质，声望-2 |
| Baron Henk | 收回合作提议 | 与Thornwall联合在木材运输上挤压你 |
| Father Lorenz | 不再主动来访 | 在社区调停中不站你这边 |

## 四、天气系统

### 4.1 天气概率池

天气按日从概率池中随机生成，概率随30天周期变化。

| 天气 | Day 1-10 | Day 11-20 | Day 21-30 |
|------|----------|-----------|-----------|
| 晴天 | 40% | 25% | 15% |
| 多云 | 35% | 30% | 20% |
| 阴雨 | 20% | 30% | 35% |
| 霜冻 | 0% | 10% | 25% |
| 大雾 | 5% | 5% | 5% |

### 4.2 天气效果汇总

| 天气 | 收割 | 采伐 | 外出 | 特殊 |
|------|------|------|------|------|
| 晴天 | 效率+1 | 正常 | 正常 | — |
| 多云 | ±0 | 正常 | 正常 | — |
| 阴雨 | 效率-2 | **暂停** | 时间+1时段 | 外出行动从2时段变为需要全天 |
| 霜冻 | ±0 | 正常 | 正常 | 未收割作物剩余量每日 -10% |
| 大雾 | ±0 | 正常 | 时间+1时段 | 林地解锁特殊描写场景 |

## 五、疲劳系统

简洁的惩罚机制，防止玩家无视晚间休息。

| 状态 | 条件 | 效果 |
|------|------|------|
| 正常 | 疲劳计数 0-2 | 无影响 |
| 疲惫 | 连续3天不休息（计数=3） | 次日所有行动效率 -1 |
| 过劳 | 连续5天不休息（计数=5） | 强制休息，失去次日上午时段 |
| 恢复 | 晚间选择"休息" | 疲劳计数归零 |

设计意图：晚间不是"免费的第三时段"。玩家需要在"晚间推进关系/办公"和"保持效率"之间取舍。大约每3天需要休息1次，但在紧要关头可以透支。

## 六、结局判定条件

Day 30结算时，系统按以下优先级判定结局（从上到下，第一个满足条件的触发）：

| 优先级 | 结局 | 条件 |
|--------|------|------|
| 1 | 结局五：发现了什么的人 | 完成Hartmann调查链全部节点（Day 3调查 + Lena文件碎片 + 林地标记调查 + 旅人对话正确选择）**且** 粮食 ≥75 |
| 2 | 结局四：被解雇 | 粮食 < 70 **或** (声望 ≤ -5 且 金卢 < 10) |
| 3 | 结局三：河谷的人 | 声望 ≥ 8 **且** 至少3个NPC信任 ≥ 3 **且** 粮食 ≥ 75 |
| 4 | 结局二：高效的机器 | 粮食 ≥ 110 **且** 金卢 ≥ 30 **且** 声望 ≤ 3 |
| 5 | 结局一：称职的外来者 | 粮食 ≥ 90 **且** 金卢 ≥ 15 **且** 不满足上述任何条件 |
| 6 | 结局四：被解雇（兜底） | 不满足以上任何达标条件 |

### 设计意图说明

- 结局五优先级最高：因为它需要最大的投入（时间+关系+正确判断），是最难达成的路线
- 结局四有两个入口：资源严重不足，或声望崩溃+金卢耗尽。也作为兜底结局
- 结局三和二互斥：高声望+深关系 vs 高产出+低社交，代表两种不同的管理哲学
- 结局一是"安全区"：只要基本面达标、没有极端偏向，就落入这个结局

### 结局三和结局五的兼容性

玩家可以同时满足结局五和结局三的条件。此时结局五优先触发——你既融入了社区，又发现了真相。这是隐含的"最完整"体验，但不标注为"最好结局"。

## 七、核心数值平衡备忘

以下是需要在实际开发中反复测试调整的关键比率：

1. **收割效率梯度**（3/5/6/7）是否让"准备投入"感觉值得？如果未准备也能轻松过关，准备就失去意义。
2. **金卢的紧张度**：日常消耗2/天是否太高或太低？目标是"需要思考但不至于焦虑"。
3. **声望的获取速度**：结局三要求声望≥8，理论最大值约13-15（如果所有加分项都拿到）。这意味着需要拿到一半以上的加分项，有一定难度但可达成。
4. **霜冻的惩罚力度**：每日损失10%是指数衰减（100→90→81→73...），5天霜冻约损失41%的剩余作物。是否太狠？可调至8%或5%。
5. **信任值的增长速度**：大多数NPC每次+1，达到信任≥3需要至少3个正面事件。30天内和每个NPC的有效互动机会约5-8次。这意味着不可能所有NPC都达到≥4，必须选择重点。
